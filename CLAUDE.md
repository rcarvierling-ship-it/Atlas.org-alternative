# CLAUDE.md

Context for future Claude Code sessions working on Lectern.

## What this is

A macOS TUI that records lectures, transcribes them locally with whisper.cpp,
and generates structured notes locally with Ollama. Python 3.12+, uv, Textual.

**Non-negotiable:** the entire AI pipeline is local. Never add an OpenAI /
Anthropic / Google / any hosted API call, and never add a "fallback to cloud"
path. If the local model is unavailable, keep transcribing and tell the user
notes are paused.

## Orientation

Read `ARCHITECTURE.md` first — it explains the pipeline and, more importantly,
why each part is shaped the way it is. `DEVELOPMENT.md` has the workflow.

```
src/lectern/
├── app.py          LecternApp: screens, services, safe quit, command palette
├── pipeline.py     RecordingPipeline: the async task graph for a live session
├── cli.py          typer CLI; bare `lectern` launches the TUI
├── services.py     AppServices (config/sessions/llm) + SessionRequest
├── doctor.py       environment checks, shared by CLI and setup wizard
├── theme.py        palette + icon set with ASCII fallbacks
├── lectern.tcss    the entire stylesheet
├── audio/          AudioSource implementations + VAD segmenter
├── transcription/  TranscriptionBackend + whisper.cpp (persistent HTTP server)
├── llm/            LLMBackend + Ollama + prompts + response parsing
├── notes/          NoteState, scheduler, updater, consolidator, finalizer
├── sessions/       storage, SQLite index, manager, recovery, export
├── screens/        one module per screen, plus modals
└── widgets/        transcript, notes, topics, status bar, recorder header
```

## Load-bearing decisions — do not undo these casually

**whisper.cpp runs as a persistent HTTP server**, not `whisper-cli` per chunk.
Reloading weights every few seconds would blow the latency budget many times
over. `WhisperCppBackend` owns that child process.

**Notes are a rolling delta merged in Python**, not regenerated by the model.
`NoteUpdater` sends the current state digest + only new speech; the returned
delta is merged by `apply_update_payload`. Merging in code means a bad response
can add nothing useful but can never silently delete an existing fact.

**Consolidation is safety-checked.** `is_safe_consolidation` rejects a rewrite
that drops >45% of items, any starred item, or any user-authored note. Keep it.

**The session clock is the audio clock**, derived from captured samples. Pausing
stops it; a sleeping Mac does not inflate the duration.

**The transcript is the priority stream.** Segments are appended and flushed
immediately with periodic `fsync`; everything else is written atomically via
temp file + `os.replace`. Any change that trades transcript durability for
notes, UI or speed is the wrong change.

**VAD counts voiced frames, not buffered frames**, for the minimum-length test —
otherwise a door slam plus hangover silence looks like speech and gets sent to
Whisper, which is where hallucinations come from.

**Schema-constrained decoding** (Ollama's `format` parameter) is what makes
typed notes work on an 8B model. `llm/parsing.py` then recovers JSON from
`<think>` blocks and fences. An unparseable response must leave notes untouched.

**`lectern` alone must be enough to start everything.** whisper.cpp is spawned
per session by the transcription backend; Ollama is started by
`ensure_ollama_running` (called once per run from `AppServices.refresh_llm_health`)
when it is installed but not answering. It refuses for a non-local host and for a
missing binary, and `doctor` never starts anything — diagnostics report state,
they don't change it. `scripts/install.sh` puts the command on PATH via
`uv tool install --editable`.

## Testing

`uv run pytest` — ~2 minutes, 191 tests, all passing.

The pipeline and acceptance tests run the **production code path** with only the
two model servers faked (`tests/fakes.py` speaks the real protocols). If you
change the pipeline, `tests/test_pipeline.py` and `tests/test_acceptance.py` are
what will actually catch it. `test_acceptance.py` is the product spec's manual
checklist, automated end to end through the UI.

To work without whisper.cpp/Ollama installed:

```bash
uv run python scripts/demo.py        # the real TUI against stub servers
uv run python scripts/screenshots.py # regenerate README screenshots
```

## whisper.cpp gotcha that already cost a release-blocker

**`whisper-server` accepts far fewer flags than `whisper-cli`**, and an
unrecognised one makes it print usage and *exit* — which surfaces only as
"whisper-server did not become ready". `--no-context` and `--language` are
whisper-cli flags; `--print-progress` is valueless, so passing it a value
leaves a stray argument. Keep the startup command minimal (`build_server_command`
is deliberately a pure function with its own test) and send language and
`no_context` with each `/inference` request instead. When startup fails, the
error carries the server's own output and the exact command — keep that.

## Textual gotchas hit already

- **Never define a method named `_render`** on a widget — it shadows Textual's
  internal `Widget._render()` and breaks layout with a confusing `NoneType` error.
- Same for `_on_mouse_scroll_up` / `_on_mouse_scroll_down`: use the public
  `on_*` handlers so the framework's own scrolling still runs.
- CSS variables must exist at **parse** time, which is before custom themes are
  registered in `on_mount`. Only use built-in variables (`$text-muted`,
  `$text-disabled`, `$border`, `$boost`, …) in `lectern.tcss`.
- `Static.content` is the public accessor in Textual 8.x (not `.renderable`).
- `rich.text.Text` has no `pad_bottom`. For hanging indents use
  `Table.grid` with a narrow marker column and a `ratio=1` body column.
- Interpolating a `Text` into an f-string throws away its spans. Use
  `Text.append_text` to keep styling.
- A `Select` raises `InvalidSelectValueError` if assigned a value that is not
  among its options — always membership-test a persisted choice first.
- Rich's console markup eats user data: `[section]` headers and bracketed
  session titles vanish. Wrap anything user-supplied in `Text`, or render with
  `Syntax`.

## Verification status

Built and verified on **Linux x86_64** (no macOS, no Apple Silicon, no Ollama,
no whisper.cpp on the build machine). What that means:

- **Verified by running:** the whole Python application — TUI, pipeline, VAD,
  scheduler, merge logic, persistence, recovery, search, exports, CLI — against
  protocol-level fakes and a WAV fixture. 191 tests pass.
- **Not executed here:** real whisper.cpp, real Ollama, CoreAudio microphone
  capture, and the Swift ScreenCaptureKit helper (`native/audio-capture/`, never
  compiled — there is no Swift toolchain on this machine).

If you are on a Mac, the highest-value thing you can do first is run
`lectern doctor`, then `lectern` with a real microphone and a real Ollama model,
and fix whatever the real integrations reveal. Start with `scripts/build-native.sh`
for the Swift helper, since it is the least-exercised code in the repo.

## Not yet built (deliberately)

Flashcards, quizzes, Anki export, slide/PDF ingest, speaker diarization,
semantic search, RAG, audio playback synced to the transcript, multi-session
knowledge base, menu-bar companion, sync. The interfaces are shaped so these are
additive; none of them should delay the core loop working well.
